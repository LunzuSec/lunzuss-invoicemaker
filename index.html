💡 How to Use This Portal
  • Select a student class and then the student name from the dropdown lists
  • Click "Generate & Download Invoice" to create a professional PDF invoice
  • The invoice includes all fee details, payment history, and outstanding balance
  • Use "Check Existing Invoices" to see all previous invoices for a student
  • All invoices are automatically saved and tracked in the system
  • You can print or email the PDF invoice directly
